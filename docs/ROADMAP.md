# Roadmap

## Verified components (scoped)

- M1: execution journal, supervisor, V2 adapter, worktree/artifact primitives and MCP contract tests.
- M2: follow-up and operation policy behavior, offline regression tests.
- M3: model/capability policy and crash recovery primitives, offline regressions.
- M4: manually managed local transport and inspect flow tested on the original Mac.

## Contribution opportunities

- Portable installation and configuration without implicit credentials.
- More independent security and interoperability tests across OpenCode versions.
- Portable CI, explicit permission/cancellation integration, well-scoped observability.
- Documentation and usability improvements, safe operation under failures.
- Opt-in restart/autostart design with process ownership and recovery validation.

All live mutation/develop capabilities and automatic services require separate validation. A private original-machine result is not a universal deployment guarantee.
