# Instructions for code-assistant contributors

This is an open-source repository, not permission to operate the contributor's computer.

- Read README, CONTRIBUTING and the security model.
- Never inspect credentials or unrelated projects or change a live OpenCode/tunnel/LaunchAgent.
- Prefer offline fake-backend tests and redacted fixtures.
- Preserve explicit approvals and avoid automatic model fallback or duplicate work.
- Do not broaden capabilities, change OS services or expose network endpoints without explicit consent.
- State what was actually tested; do not present mocks as live proof.
